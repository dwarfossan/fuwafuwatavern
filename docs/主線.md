# 主線架構（大爺 10-21 重新確認）

> **這是已定的故事架構，不是全部劇情細節。** 三條線各自的劇情內容、真相、角色，沒有大爺明說的都還沒定，AI 不要自己補成設定。
> 動到劇情、地點內容（森林、洞窟、城鎮事件）之前先看這份。

## 核心
城鎮、森林、洞窟**各有一條完整主線**，三條彼此影響，最後匯集成共同的大主線。
不是「第一章、第二章、第三章」的單一路線：重點不是先去哪裡，而是**玩家做過什麼，會改變其他地方發生的事**。

## 已談過的內容
- **序章**：四隻從軟呼呼酒館出發，途中營救商隊，隨商人進城，成立冒險小隊（已做好）
- **城鎮線**：認識城鎮人物、接觸冒險者公會，從各種委託和事件展開故事
- **森林線**：調查森林異常安靜、鳥獸消失、熟悉的道路卻會走錯等現象。一條**獨立的神秘探索**主線
- **洞窟線**：公會的「驅除哥布林」委託，報酬全隊 200G，目標是鎮外有二十幾隻哥布林的山洞
- **獨眼獸人事件**：前往森林的路上可能遭遇獨眼獸人率領的強盜團；就算沒先接通緝委託，也可以事後回公會領賞（外觀 `orc_captain` 已有）
- **三線交會**：森林、洞窟與城鎮的事件結果會互相牽動，最後共同推動更大的故事
- **森林不要又是一堆哥布林**（兩邊都打哥布林是大爺不要的）

## 大地圖的驚嘆號（大爺 10-22）

- **黃色 ❗＝支線**（每日委託、梟熊寶寶、獨眼獸人）

## 寫法：諷刺＋幽默（大爺 10-21）
- **洞窟**：狗頭人宗教諷刺（狗頭人把紅龍幼龍當神拜）
- **城鎮**：政治諷刺（**先不做**，大爺 10-21）
- **森林**：外來種被棄養（大爺 10-21 定）
  - 貴族棄養的**奇美拉**、**食人花**（叫食人花，不叫食人草）丟進森林，把原本住在森林的**哥布林**趕了出來
  - 逃出來的哥布林**只會掠奪城鎮**——這樣才是哥布林（大爺：不是可憐的難民）
  - **德魯伊**應該維護森林的平衡，卻因為**討厭哥布林**，默許平衡被破壞（大爺選的私心）
  - 諷刺的重點（大爺 10-21）：哥布林只會掠奪，只是讓她**討厭得有正當性**，但不代表能默許外來種破壞生態。她的職責是整座森林的平衡，**失職才是重點**——真正的受害者是森林本身（鳥不叫、野獸不見、原生植物被食人花擠掉）
  - **森林主線的流程（大爺 10-22）**：公會小姐那邊得知哥布林是從森林過來的 → 開始調查 → 遇到德魯伊，得知她討厭哥布林 → 之後遇到食人花，得知食人花的花粉對奇美拉有催眠作用 → 才知道有奇美拉，而且是德魯伊控制的
  - 大爺 10-22 同意：①德魯伊「一步步陷下去」：先默許（奇美拉會趕走哥布林就不管），後來發現花粉能催眠奇美拉，乾脆拿來控制、專門對付哥布林（默許→利用，失職的重點不變）②怎麼得知花粉的事：食人花旁的調查點（被採過花粉的痕跡、她掉的花粉袋、巨大爪痕和三種毛）讓玩家起疑，最後親眼撞見她用花粉讓奇美拉睡著
  - 還沒定：棄養的貴族是誰、德魯伊的私心怎麼被揭穿、這條線怎麼收尾、跟洞窟／城鎮怎麼交會（洞窟二十幾隻哥布林是不是森林逃出來的，**沒定**）
