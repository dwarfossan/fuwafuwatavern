# 裝備 → 技能表

> 2026-10-01 前由舊的 `data/skills.js` 自動產生。產生器已經刪除，這份不會再自動更新：技能資料以 `data/skills.js` 的 `SKILL_GROUPS` 為準，改了技能要手動更新這份。
> 註：技能的來源正在改成「觀察學習＋小筆記」，見 `docs/小筆記規格.md`。沒有職業，技能全部來自裝備。

**共通數字**：命中 = d20 + 屬性調整值 + 2 ≥ 目標 AC｜豁免 DC = 8 + 2 + 屬性調整值｜生命值（1 級）= 8 + 體質調整值｜1 格 = 5 呎｜檢定直接用六圍

**熟練點數池**：每個角色一個池，一級 2 點。普攻、戲法不花點數；其他招式花點數。**升環**：多花點數讓效果變強，每多 1 點多一份升環效果；單招最多花「等級 + 1」點。休息系統做好前，每場滿點數開打。

**類型**＝判定方式・傷害。判定方式：**近戰**／**遠程**＝擲攻擊骰對 AC；**豁免**＝對方擲豁免；**輔助**＝不打人。一招有兩段的，照第一段擲的骰算。傷害：**物理**＝武器或身體本身的力量（不再分揮砍、穿刺、鈍擊）；**法術**＝法術、神術不帶元素的；**特殊**＝其他力量（氣……）；**元素**優先，帶元素的直接寫元素（火焰、強酸……），不管從法術、道具還是龍嘴出來。輔助和不造成傷害的招只寫判定方式。

**基本攻擊**的名稱看手上的武器：砍的**斬擊**、戳的**刺擊**、砸的**打擊**（含徒手、法杖）、用彈藥的**射擊**、標槍飛鏢**投擲**。

**武器**：固定普攻（不花點數）＋三個普通招式。沒有大招這種突然很特別的招式（大爺決定）。說明只看武器屬性（投擲、觸及、靈巧……），不寫武器名稱，以後好替換。盾牌 1 招；護甲只有被動數值。

**法器**：法杖／法書／法球，每件綁定一組法術，以主題命名；法杖另外能敲人。只拿法器、又沒有不花點數的攻擊（治癒法書）時，普攻是徒手。施法屬性：法杖＝智力、法書＝感知、法球＝魅力。標 ✦ 的法術取自 SRD 5.2。
