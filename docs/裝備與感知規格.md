# 裝備與感知規格（2026-10-02）

> 大爺 10-02 定的。程式位置寫在每節最後。

## 一、感知：看穿敵人身上帶的東西

照 D&D 的主動／被動感知，全遊戲同一套（伏擊劇情的被動察覺本來就是 10＋感知）。

| | 被動感知 | 主動：搜索 |
|---|---|---|
| 算法 | 10＋感知調整值，不擲骰 | d20＋感知調整值 |
| 對什麼 | 敵人藏東西的 DC | 同左 |
| 什麼時候 | 敵人**第一次被看到**時（開戰時看得到的、躲著的敵人現身時），四小隻**各自**比一次，夠高的就看穿 | 玩家自己用：動作選單 →「搜索」 |
| 花費 | 不花 | **免費動作**（用過了改扣主動作，跟道具一樣）。D&D 的搜索是主要動作，這裡是改良 |
| 範圍 | — | 6 格內、看得到（沒躲著）的敵人 |

- **敵人藏東西的 DC＝10＋敏捷調整值＋2**（2＝低階怪的熟練加值）。哥布林 DC 14：被動要感知 18 才看得穿，大多要靠搜索
- 看穿了、或**打倒之後**，那隻的背包就能打開；**整場戰鬥四小隻共用**
- 搜索失敗下回合可以再試；已經看穿的不會出現在搜索目標裡
- 紀錄會寫是誰看穿的；看穿時**還沒有台詞**（台詞大爺之後寫）
- 骰子面板：搜索成功顯示 **FOUND**（暫定的字）、失敗 FAIL
- **偷竊**成功也要能打開背包（大爺 10-02），偷竊還沒做

> 找**躲起來**的人（大爺 10-02 統一）：回合開始時，對移動格數內躲著的對手用**被動感知**比對方潛行擲的數字，不擲骰。主動「搜索」擲一次 d20＋感知，**同時**看穿點的那隻身上的東西、找 6 格內躲著的；附近沒有能看穿的就直接搜四周（按鈕只要有免費動作就能按，不然等於告訴玩家附近有東西）。潛行沒過 13＝沒躲好。躲著的敵人完全看不到（沒有 ???）；被察覺或從藏身處出手時，骰子面板攤開潛行骰對被動感知（DM 明著骰，見 `docs/現況.md` 第三節）。

程式：`passivePer`、`pocketDC`、`pocketKnown`、`passivePocket`、`SEARCH_RANGE` 在 `js/battle/engine.js`；`searchTargets`、`doSearch` 在 `js/battle/flow.js`；測試 `tests/perception.mjs`

## 探索偵測（10-03 大爺確認）

- 我方每一步用原本移動格數（senseRange）察覺躲藏敵人；被動感知對潛行，並沿用 coverOf 檢查樹／馬車遮擋。找到時攤開潛行與被動感知骰，不改戰鬥察覺規則。
- 敵人偵測距離寫在 ENEMIES.detectRange：哥布林 5、弓手 7、薩滿 6。範圍外一格黃警示；進範圍且沒有四分之三掩護遮擋，沒潛行直接被發現，潛行用被動感知對擲出的數字。
- 選取敵人的偵測格只在探索潛行時顯示，放地板層；黃紅警示放最上層 hudSVG。探索 v1 被發現全隊停止，切戰棋後續另接。
- 隱藏敵人格不在探索尋路裡洩漏；实际碰撞不能重疊。程式 js/battle/explore.js，測試 tests/explore.mjs。

## 二、狀態卡

### 四小隻
- 頂端：生命・AC・移動・**被動感知**
- 動作／免費／移動燈號：**只在牠的回合**顯示
- **熟練格一律顯示**，跟戰場上一樣收合：平常只有 I；點下面的細條**往下**展開 II 以上（兩欄，左欄排滿再排右欄）。戰場上往上長，卡片裡往上會撞到標題，所以往下
- 裝備格（10-02 對齊）：飾 I ↔ 背包同一排、飾 II ↔ 身體同一排，主手、副手在下面
- 裝備格標籤固定在上方，圖示在下方獨立位置（10-02 GPT 手機介面第三批，`story` 待驗）；四小隻與敵人共用，避免護甲圖示蓋住「身體」。

### 敵人、NPC：跟四小隻同一個版面（參考 BG3 的檢視）
| 項目 | 敵人卡片 |
|---|---|
| 紙娃娃＋裝備格 | 有，**只能看不能拖**；點裝備看說明 |
| 六圍 | 有。敵人資料只有調整值，所以只顯示 +2、−1 |
| 狀態圖示 | 有 |
| 背包 | 平常「？」鎖著；看穿或打倒後打得開 |
| 熟練格、燈號 | **不顯示**（熟練格規格：敵人的格子不顯示） |
| 小筆記分頁 | 沒有 |

- NPC 用同一張卡片，背包一律鎖著（感知只算敵人）
- 寬度跟四小隻一樣 260px（以前敵人卡片撿到舊版面的 620px）

程式：`infoHTML`、`slotGridHTML` 在 `js/battle/render.js`

## 三、身體裝備的外觀：三層＋錨點

- 身體裝備的畫法（`ARMOR_ART`）可以是一段圖（只有身上），或分三層：
  - **body**：蓋在身上。大家共用同一個身體形狀，誰穿都對得上
  - **neck**：項鍊之類，以「頸錨點」為原點
  - **head**：頭飾，以「頭錨點」為原點，畫在**頭上面**
- 錨點每種外觀一組：`head:[x, y, 縮放]`（頭的 100×100 座標，原點＝額頭正中、布帶的位置）、`neck:[x, y]`（紙娃娃座標）
  - 四小隻：`CRITTER_ANCHOR`（`js/art/doll.js`）。頭比哥布林圓、大，頭飾放大約 15%、往上一點。**目測的，大爺看過再調**
  - 哥布林：`GOBLIN_ANCHOR`（`js/art/monsters.js`）
- 頭像（先攻列的小圓圈）不跟著裝備變：薩滿的頭像照舊畫骷髏頭，認得出是牠

## 每件法器的施法屬性（10-03 大爺確認）

每件法器生成時在 INT／WIS／CHA 等機率擇一，之後固定，商店現貨與買下的同一件一致；新現貨另生成。`makeItem` 建立唯一識別，`itemById` 解析模板或實例，state.focusItems 保存實例，inv 保存識別；舊模板法器在 invItems 首次讀取時轉為實例且只轉一次。敵人生成與掉落保留實例，重新挑戰還原原法器；不是每次施法抽。命中、法術豁免 DC、治療加值都用持有法器的屬性，法器近身敲擊仍用力量。裝備卡顯示實際屬性。這是本作自訂規則，尚無持久進度存檔，重新整理仍重建整個遊戲。

霜雷法杖（暫定 GPT）：20 gp、4 lb，沿用奧術法杖紙娃娃外觀，以 elementFocus 標記；打擊走 arcane_staff，item.grants 給兩種元素戲法，裝備卡列出 grants。沒有原法杖的額外火焰箭。

## 隱藏油（10-03）
草叢底下的油沿用被動感知 10＋感知；我方範圍 senseRange、敵方 detectRange；coverOf 四分之三掩護以上擋察覺。DC13 暫定 GPT。探索每步／戰棋移動與回合開始檢查；主動搜索沿用同一個 d20＋感知與 6 格範圍，不額外扣動作。每個敵人的 knownGround 分開，不因玩家發現就全知；只有我方發現才設定油的 found 並顯示棕色平塗（外觀暫定 GPT）。失敗不透露油存在。油本身沒有新增滑倒或傷害規則，點燃後是既有火地面，AI 看得到火後才按既有危險避讓。隨機場暫定 3 處，置於非出生點草叢內，不改固定伏擊。

## 封印奇物與每週自選（10-03 GPT）
道具店魔法物品頁頂端的「？」首次點開，四小隻依序問，莉莉安娜用封印／解封費介紹，八句全為 draft:"GPT" 草稿；以原詳細框與頭像／代表SVG演出。看完才可解封，之後直接開付費確認。
解封費暫定5 gp，由目前頭像付款；魔法70%、稀有25%、傳奇4%、獨特1%。連續九份沒出稀有以上，第十份至少稀有（保底修正後該次機率不同，頁面明示）；每份留一枚封印印記，50枚自選本週公布的橙／金物品。印記不因抽中高階或換週歸零；十次進度也跨週。長休一天，第1～7日第一週，8～14日第二週，依此類推。首週公開非凡長弓（狩印）及次元背包（負重兩倍），次週守夜人的披風（減重／火焰抗性）與風隙長弓（命中+1／閃電附傷），後續按此兩組輪替，效果在兌換前可直接看，短來歷在原物品卡。這是第一批暫定目錄，不虛構未做的獎品。
抽取結果依商店種子與已解封次數固定；付費時先保存實例、印記、保底，再顯示待領取。揹不動或不符裝備力量／敏捷要求可換頭像領；未領前不能再解封，不會掉獎或重抽。兌換檢查本週名單、印記、負重及裝備限制，扣印記、不扣金幣。解封／兌換品不可退換（防原本全額退貨反覆免費取得印記），一般現貨退貨不變。商店帳本保存週目錄、看過介紹、未領物品、印記／保底／次數，try/catch；依舊不是整個遊戲進度存檔。tests/sealed-goods.mjs 跑50次、最大連續藍9、邊界機率、兌換後印記0且不扣錢、週更新不清紀錄、無款／超重／重複防護及390×844實際觸控。
