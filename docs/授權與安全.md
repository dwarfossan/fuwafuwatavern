# 授權與安全（2026-10-02）

> 從 D&D 借東西之前先看這份。這是公開資料整理出來的做法，**不是法律意見**；要上架賣之前，找懂授權的人確認一次。

## 一、我們借了什麼、用什麼授權

- 規則以 **SRD 5.2**（System Reference Document 5.2，威世智 Wizards of the Coast 官方公開的規則文件）為底
- 也借 **SRD 5.1**（2014 版規則）：大爺 10-02 定，5.2 沒有、5.1 有的規則可以用，但要標 5.1 的出處。目前借用：奇襲個別判定
- SRD 5.1、5.2 都用 **CC-BY 4.0** 授權（5.1 是 2023 年 OGL 風波後改的）：可以商用、可以改，**唯一條件是標示出處**。CC 授權給出去就**收不回來**
- 目前借用：屬性值與調整值算法、4d6 取高三、武器與護甲數值（傷害、屬性、價格、重量、AC、力量需求）、武器專精名稱、部分道具與怪物數值、攀爬與跌落規則、標 SRD 的法術
- 角色、世界觀、地圖、劇情、美術：全部原創

README 最後的「授權與出處」就是 CC-BY 要求的標示（**不是免責聲明**），一定要留著。

## 二、一定要守的

| 不要做 | 舉例 |
|---|---|
| 用 D&D 的名稱、商標 | 「Dungeons & Dragons」「D&D」「Dungeon Master」「D20」出現在遊戲畫面、標題、宣傳 |
| 用 SRD **沒收錄**的內容 | 官方設定的怪物（例如眼魔）、世界觀（被遺忘國度）、SRD 以外的法術、職業、專長名稱 |
| 暗示官方背書 | 「官方授權」「D&D 認證」這類字眼 |

- 開發文件、程式註解裡寫「照 D&D」沒關係，玩家看不到
- **從 D&D 借新東西進來之前，先確認它在 SRD 5.2 或 5.1 裡面**，並記下是哪一份；每加一批就對照 SRD 5.2 核對一次（README 第 6 節）
- 法術、怪物照 SRD 的，在資料裡標 `srd:true`（技能表上會出現 ✦）

## 三、類似遊戲的案例

| 案例 | 發生什麼 | 原因 | 給我們的教訓 |
|---|---|---|---|
| **Solasta: Crown of the Magister**（電腦遊戲，2021） | 用 SRD 5.1 做的商業戰棋 RPG，正常上架販售，沒有出事 | 只用 SRD 規則，世界觀、角色全部自創 | **跟我們最像，走同一條路** |
| **5e 輔助 App**（d20 Fight Club 等，5e 初期） | 收到停止函，下架 | 放了 SRD 以外的內容（城主指南），用了「Dungeon Master」「D20」商標字 | 刪掉非 SRD 內容、改名後重新上架。**只能用 SRD 的東西** |
| **TSR LLC《Star Frontiers: New Genesis》**（2022） | 被威世智提告 | 用了威世智的商標（TSR、Star Frontiers），內容另有種族歧視爭議 | **商標不能碰** |
| **OGL 1.1 風波**（2023） | 威世智想收回舊的開放授權，玩家和出版社大反彈 | — | 威世智全面讓步，SRD 5.1、之後的 5.2 改用 CC-BY 釋出，收不回來，**對我們更安全** |

結論：被找麻煩的都踩到 SRD 以外的內容或威世智的商標；只用 SRD、內容原創的，查到的資料裡沒有出事的例子。
