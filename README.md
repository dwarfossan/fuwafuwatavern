# 毛絨絨小隊（軟呼呼酒館）

瀏覽器上的 TRPG 風格遊戲，手機優先。四隻小動物住在矮人大爺的酒館，出門冒險學東西回家：
🦊 玲玲（狐狸）、🐯 嬌嬌（白虎）、🐺 香香（灰狼）、🦝 默默（狸貓）。

- 線上版：https://dwarfossan.github.io/fuwafuwatavern/
- 直接進快速戰鬥：https://dwarfossan.github.io/fuwafuwatavern/#battle

---

## 接手的 AI 先看這裡

### 1. 程式只有一個檔案：`index.html`

2026-10-01 起，**整個遊戲就是 `index.html` 這一個檔案**（HTML＋CSS＋JavaScript 全部在裡面，約 5800 行）。
舊的 `js/`、`data/`、`css/`、`tools/`、打包工具都已經刪掉了。

- 要改什麼，就直接改 `index.html`，用函式名稱或中文註解搜尋
- 沒有建置步驟、沒有打包。改完就是成品
- 不要重新拆成多個檔案、不要建打包流程，除非大爺要求

### 2. 分支規則

- 改東西推到 **dev**，**絕對不要直接推 main**
- main 是大爺確認過的穩定版，網站讀的是 main。大爺說「好了」才把 dev 合併進 main
- **每做完一項就 commit 一次並推上 dev**，訊息寫清楚改了什麼。不要累積在本機或聊天檔案裡（之前就是這樣弄丟進度的）

### 3. 給大爺測試

- 網址加 `#battle` 直接進快速戰鬥
- 要給大爺「一打開就進戰鬥」的檔案：複製 `index.html`，把最後面的
  `if(location.hash==="#battle") quickBattle();` 換成 `if(true) quickBattle();`。**repo 裡的 `index.html` 不要改成 `if(true)`**

### 4. 實作紀律（大爺確認，所有 AI 都要遵守）

1. **大爺指定改哪一層，就改那一層。** 圖層、資料結構、規則、架構的要求，要真的改那一層，不能用外層 transform、逐物件補丁、反向補償冒充完成
2. **先提、再改。** 有更好的做法，先說理由，等大爺點頭。設計還沒定的地方先問，不要自己決定
3. **不要偷塞自己的東西。** 只改被要求的部分。自己寫的台詞、暫定的外觀，要標明是草稿／暫定
4. **大爺說的跟程式不一樣時，直接指出來**，不要默默照其中一邊改
5. **先複述理解，再動手**
6. **測試要如實描述。** 語法檢查（`node --check`）只代表能解析，不代表功能正常。有在瀏覽器實際跑過、截圖看過，才能說測過；沒測的就說沒測
7. **原本就有的問題：講出來，但不擅自修**
8. **不要把 workaround 疊成技術債。** 方向錯了就回到正確結構重做
9. **被要求判斷時給明確立場**，不要兩邊都講

**鏡像實驗的教訓**：曾經用「整層鏡像再把字翻回來」和「每個物件原地翻面」想把畫面左右翻轉，都不對，已撤銷。
10-01 改「由右到左」的正確做法是**改資料**：大地圖地點 x 改成 1000−x；斜角戰場畫面左右相反＝格子 x、y 對調；開場朝向對調。沒有翻轉任何東西。

完整的合作案例（包括 AI 自己犯的錯）：`docs/對話紀錄_2026-10-01.md`

### 5. 其他規則

- 借用 SRD 的數值，每加一批就對照 SRD 5.2 核對一次

- 玩家看得到的文字用**繁體中文**；頭上彈字用英文（MISS、CRITICAL! 等，在 `POP_TEXT`）
- 規則以 SRD 5.2 為底，會為了好玩改。遊戲裡不出現 D&D 的名稱或商標
- 大爺的個人設定（自畫像等）不是遊戲內容，沒說要做就不要放進遊戲

## 2026-10-01 做了什麼（Claude）

- 小筆記：一頁 5 招（玲玲 3 頁、其他 2 頁）；向玲玲學的 DC 用招式原本的怪物等級（起始技能算 1 級）
- 被動觀察的符號演出：白色泡泡框，❗紅色彈出、❓藍色左右搖擺、…黑色一點一點冒出
- **方向改成由右到左**：戰場 x、y 對調（23×26），大地圖酒館在右、洞窟在左
- 大地圖回程路線修正：棋子永遠沿著畫出來的路走
- 補上 GitHub dev 的劇情修正：擲屬性頁排版、劇情全畫面點擊推進、換台詞不閃爍
- 按鈕去掉「牆」：「去看裝備」「回裝備」
- 伏擊劇情：哥布林改拿短棒、彎刀、弓；加草叢；四小隻被動察覺（10＋感知），有人察覺草叢會晃、吐槽，進戰鬥薩滿直接現形
- **NPC 陣營**：商人大叔（暫定外觀）站在馬車後面。`hostile()` 統一判斷敵對，NPC 不是任何人的敵人、不擲先攻、不行動
- 默默改成狸貓配色
- 投擲物照丟的東西換圖（瓶子、網子、武器圖示），軌跡改直線
- **高度地形**：西南角兩層高的斷層台地。往上一層多花 1 格移動；兩層以上要爬下來；距離把高度差算進去（隔兩層打不到）；推下 10 呎受 1d6 並倒地；掩護看直線在每格的高度
- 頭上提示（狀態圖示、台詞、觀察符號）改成跟著地圖縮放，最小保留 60%
